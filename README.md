# LSA Games 成绩管理系统

一台电脑作主机,同一局域网内的手机/平板/电脑通过浏览器访问;所有数据保存在主机 `data/meet.db`。

## 启动
- Windows:安装 Python 3.9+ 后双击 `start.bat`(首次自动安装依赖,需联网一次)。macOS/Linux:`./start.sh`
- 控制台会显示访问地址与初始管理员密码(同时保存在 `data/管理员密码.txt`)。其他设备打开 `http://主机IP:8000`。
- 忘记密码:`python app.py --reset-password`;更换端口:`python app.py --port 8080`。
- 打不开时:检查主机防火墙是否放行端口,以及 Wi-Fi 是否开启“客户端隔离”。

## 赛前流程
1. 设置:改管理员密码、名次分/参与分/破纪录加分;在“录入员账号”里为各项目建账号(可“按项目一键生成”),把账号密码发给各赛场裁判。
2. 队伍分组:建队伍(支持层级,如 年级→班级)。
3. 人员:批量导入(可从 Excel 粘贴)→ 自动编号 → 未分队者“自动均衡分队”。
4. 项目:一键添加常用项目,再设置时间、场地、纪录。
5. 项目详情:添加报名 → 分组与跑道。自动分组有三种:随机抽签、**按号码大小**(号码小的在前面的组)、按报名成绩;也可选**手动分组**(只建空组,用每行的「组」下拉自己分配,可「+ 新增一组」「删除本组」)。
6. 时间表页自动检查运动员时间冲突。

## 比赛日
- 项目详情 →「成绩录入」:不同组分段显示(每段有组名、时间、已录入数),前三名自动高亮;输入成绩回车即保存并跳下一行,可按号码定位。时间 `12.34` 或 `1:05.20`,田赛为米。
- 积分榜实时更新,「大屏」可投屏;他人修改后其他设备约 4 秒自动刷新。

## 计分规则
名次并列者平分所占名次得分;完赛参与分每个有效成绩计一次;第一名优于项目纪录时加破纪录分;上级队伍总分 = 自身 + 全部下级。

## 备份
设置页可下载数据库备份,或直接复制 `data/meet.db`。

## 批量导入人员(含报名项目)
「人员」页 → 批量导入:粘贴 Excel 表格或选择 CSV 文件,第一行为表头,列顺序任意:
`姓名`(必填) `性别` `年级` `班级`(或队伍) `号码` `项目` `组别` `备注`。
- 「项目」列可填多个,用 、 或 ; 分隔,如 `100米、跳远`;系统按性别自动补“男子/女子”,也可写全名。
- 号码相同、或姓名+队伍相同的人员视为同一人:更新其信息并追加项目,不会重复创建。
- **自动创建项目**:导入时若项目不存在,按「项目 + 性别 + 组别」自动创建,如 `100米` + 男 + `甲组` → “男子100米甲组”。含“接力”的建为接力项目,含“跳/掷/铅球”等的建为田赛,其余为径赛。没有“组别”列时自动按“年级”列分组别(如 G1、G2-G3 各建一套项目);性别留空的学生建不分性别的项目。可取消勾选“自动创建不存在的项目”;“组别取自”可选“组别”列、“年级”列或不分组别。
- 接力项目不会按个人报名(需在项目页按队伍报名);性别不符的项目会在导入结果中逐行提示;可在窗口里下载模板。
- 导入后可在「人员」页点「编辑」修改年级、队伍、号码、备注及报名项目;支持勾选后批量改队伍/年级/删除。

## 项目类型、单位与报名上限
- 类型:径赛(计时,越小越好)、田赛(距离/次数,越大越好)、**游戏(团队项目,记分制,得分越高越好,不设跑道)**、接力。接力与游戏都**按队伍参赛**:每队一条参赛记录,可编辑参赛队员,名次分使用「接力名次分」。导入时按名称自动判断(含“抢、大摆锤、步步为营”等归为游戏),可在项目页批量修改类型;个人项目改为游戏/接力时,原有个人报名会自动并入队伍报名。
- **成绩单位**:每个项目可单独设置(秒/米/分/次/厘米…),留空按类型默认;导入时跳绳、仰卧起坐自动为“次”,坐位体前屈为“厘米”。
- **报名上限范围**(设置页):「每人最多报名」只统计勾选的项目,未勾选的(如游戏类)不占名额;接力、游戏(按队伍参赛)不计入。也可在项目编辑/批量修改里逐个设置。
- 项目显示名为“名称(组别)”,如“男子100米竞赛(G2-G3)”。

## 接力队员
导入名单时,报名了接力的人会记为候选,并为各队自动建立接力队。进入接力项目页,点队伍旁的「编辑队员」,从该队人员中按棒次顺序选出上场队员(人数在设置里的“接力每队人数”调整,默认 4)。同一接力项目中,一人不能同时出现在两支队伍。

## 统一的批量操作(项目页、人员页一致)
- 每行最左是勾选框,其后是「编辑」按钮;表头勾选框全选当前筛选结果,Shift 可连选。
- 勾选后底部出现**操作条**:显示已选数量、全选/反选/取消,以及「批量修改」「删除」等操作。
- 「批量修改」是同一种窗口:每个字段左侧有勾选框,**只修改勾选的字段**;在右侧填写会自动勾选;勾选后留空表示**清空**该项(如清空场地、组别)。
- 设置页按「赛事规则 / 账号权限 / 数据与日志 / 访问与检查」分栏。

## 项目批量管理
「项目」页默认按**组别、男女分段**显示(每段有标题行,可一键勾选整段;排序里可选“不分组(平铺)”);项目详情页左上角有「返回项目列表」。
「项目」页(管理员):
- 顶部可按类型、性别、状态、场地、组别筛选,或搜索;支持按开始时间/名称排序。
- 勾选项目(表头可全选当前筛选结果,Shift 可连选),出现批量工具条:**批量修改**(场地/组别/类型/性别/时间/时长/道数/状态/单位/是否计分/是否计入报名上限/备注)、**排时间**(按显示顺序依次排定,可让不同场地并行)、**整体平移**(整体提前或推迟若干分钟,分组时间同步)、**生成分组**(为多个项目一次生成分组与跑道)、**删除**。
- 推荐流程:导入名单(自动建项目)→ 筛选“田径场”全选 → 排时间 → 全选 → 生成分组。

## 升级说明
从旧版升级只需替换 `app.py` 与 `static/index.html`,原有 `data/meet.db` 会自动增加“年级”字段,数据保留。

## 录入员账号(按项目授权)
- 登录时填「账号」+「密码」;管理员账号为 `admin`。
- 录入员账号只能录入、修改**被分配项目**的成绩和状态,其他项目只读;一个账号可负责多个项目,一个项目也可有多个账号。
- 设置页 →「录入员账号」:新建/编辑账号并勾选负责项目;「按项目一键生成」为每个项目各建一个账号(r01、r02…,随机 6 位密码)。
- 密码只在生成/重置时显示一次(可复制或下载 CSV)。忘记了只能重置;重置、改账号、删账号会让对方立即下线。
- 旧版的“共享录入员密码”已取消,请改用账号。
